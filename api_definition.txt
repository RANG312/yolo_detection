a) 发送识别任务接口
        请求方式: POST
        接口路径: /api/v1/recognition/tasks

        请求体 {
           "req_id": "uuid",   -- 请求uuid，可选；不传则服务端自动生成
           "image_path": "/root/xxx/image/a.jpg,/root/xxx/image/b.jpg",
                               -- 图片URL地址或本地图片地址，多个图片以英文逗号分隔
           "data_type": [
               {"recognize_type": "1", "recognize_subtype": "3"},
               {"recognize_type": "6", "recognize_subtype": ""}
           ],
                               -- 识别类型及子类型数组
                               -- 当前业务规则：一张图只做一种检测
                               -- 当 image_path 有多张图时：
                               -- 1. 如果 data_type 只有1项，则该检测项复用到所有图片
                               -- 2. 如果 data_type 有多项，则数量必须与图片数量一致，并按顺序一一对应
           "extra_info": ""    -- 其它说明，支持json字符串
        }

        对应关系说明:
        1. 单张图 + 单个data_type
           "image_path": "a.jpg"
           "data_type": [{"recognize_type": "1", "recognize_subtype": "3"}]
           表示: a.jpg 做表计识别

        2. 多张图 + 单个data_type
           "image_path": "a.jpg,b.jpg,c.jpg"
           "data_type": [{"recognize_type": "6", "recognize_subtype": ""}]
           表示: a.jpg、b.jpg、c.jpg 都做火源检测

        3. 多张图 + 多个data_type
           "image_path": "a.jpg,b.jpg,c.jpg"
           "data_type": [
               {"recognize_type": "1", "recognize_subtype": "3"},
               {"recognize_type": "6", "recognize_subtype": ""},
               {"recognize_type": "7", "recognize_subtype": ""}
           ]
           表示:
           第1张图 a.jpg 对应第1个data_type，做表计识别
           第2张图 b.jpg 对应第2个data_type，做火源检测
           第3张图 c.jpg 对应第3个data_type，做安全帽检测

        注意:
        - 当前不支持一张图同时做多种检测
        - 如果 image_path 数量 > 1 且 data_type 数量 > 1，但两者数量不相等，则请求报错
        - 火源检测和安全帽检测没有 subtype 概念，recognize_subtype 允许为空字符串
        - 表计识别当前允许所有 subtype，recognize_subtype 为空时服务端会自动补成 "default"

        响应体 {
           "req_id": "uuid",     -- 响应uuid，与req_id一致
           "code": 0,            -- 应答返回码 0-成功 1-失败
           "resp_msg": "Task accepted successfully.",
           "data": {
             "task_status": "processing"  -- processing (处理中)、pending (排队中)、finished (处理完成)
           }
        }


b) 查询任务状态接口
        请求方式: GET
        接口路径: /api/v1/recognition/tasks/{req_id}

        响应体 {
           "req_id": "uuid",
           "code": 0,
           "resp_msg": "success",
           "data": {
             "task_status": "processing",
             "created_at": "2026-04-08 14:00:00",
             "updated_at": "2026-04-08 14:00:03",
             "callback_payload": {},
             "callback_status_code": 200,
             "callback_error": null,
             "error": null
           }
        }


c) 上报识别结果接口 (回调接口)
        这个接口由识别服务在识别完成后主动调用。
        请求方式: POST
        接口路径: /api/v1/recognition/callback

        请求体 {
            "req_id": "uuid",
            "data_result": [
                {
                    "image_path": "/root/xxx/image/a.jpg",          -- 原始图片
                    "image_path_result": "/root/xxx/result/a.jpg",  -- 识别结果图
                    "recognize_data": [
                        {
                            "meter_index": "1",
                            "recognize_type": "1",
                            "recognize_subtype": "3",
                            "recognize_value": "0.523456",
                            "confidence": "100",
                            "recognize_desc": "识别成功，表计#1归一化读数为0.523456，arc_mode=clockwise"
                        }
                    ]
                },
                {
                    "image_path": "/root/xxx/image/b.jpg",
                    "image_path_result": "/root/xxx/result/b.jpg",
                    "recognize_data": [
                        {
                            "meter_index": "1",
                            "recognize_type": "6",
                            "recognize_subtype": "",
                            "recognize_value": "fire",
                            "confidence": "92",
                            "recognize_desc": "识别成功，火源检测检测到fire，置信度=0.9231"
                        }
                    ]
                }
            ],
            "code": 0,
            "resp_msg": "Task finished successfully.",
            "finish_time": "2026-04-08 14:10:53"
        }

        字段说明:
        - image_path: 原始输入图片路径
        - image_path_result: 结果图路径
        - recognize_data: 当前图片的识别结果列表

        recognize_data 字段说明:
        - meter_index:
          表计场景表示第几个表计实例
          检测场景表示第几个检测框
          未检出目标时固定为 "0"
        - recognize_type:
          识别类型，见下表
        - recognize_subtype:
          子类型；火源检测和安全帽检测通常为空字符串
        - recognize_value:
          表计场景为归一化读数
          火源/安全帽场景为检测类别名
        - confidence:
          表计当前固定为 "100"
          检测场景为置信度百分比整数
        - recognize_desc:
          识别结果描述


d) 健康检查接口
        请求方式: GET
        接口路径: /health

        响应体 {
           "code": 0,
           "resp_msg": "ok",
           "data": {
             "status": "healthy",
             "time": "2026-04-08 14:11:00"
           }
        }
